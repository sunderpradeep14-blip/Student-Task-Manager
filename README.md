# 🎓 Student Task Manager

A simple CRUD-based web application developed for **VSB Skill Vault – Activity 3**.

## 📌 Project Overview

The Student Task Manager helps students organize and manage their academic tasks. Users can add, view, update, complete, search, filter, and delete tasks.

## ✨ Features

- Add new student tasks
- View all tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter by status
- Filter by priority
- Dashboard task statistics
- Data persistence using browser LocalStorage
- Responsive design for desktop and mobile

## 🔄 CRUD Operations

### Create
Students can create a new task by entering the task title, subject, description, due date, priority, and status.

### Read
All saved tasks are displayed as task cards.

### Update
Existing task details can be edited using the Edit button. Tasks can also be marked as completed.

### Delete
Users can permanently remove a task using the Delete button.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The application will open in your web browser.
5. Add and manage your tasks.

No server or database installation is required.

## 💾 Data Storage

The application uses the browser's **LocalStorage** to store tasks. Therefore, tasks remain available after refreshing the page on the same browser.
